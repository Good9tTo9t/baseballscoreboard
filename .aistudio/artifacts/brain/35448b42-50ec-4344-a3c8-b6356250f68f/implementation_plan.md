# 攻守紀錄表更新與逐打席紀錄表 (Play-by-Play) 實作規劃

## 需求總結
1. **在攻守紀錄表旁新增「逐打席紀錄表」**：
   - 記錄逐打席發生的事件。
   - 包含當下出局數（0出局 / 1出局 / 2出局，附指示燈號）。
   - 包含幾壘有人（迷你壘包菱形鑽石 + 文字標示）。
   - 包含打席結束時幾好幾壞（B-S 球數與球數燈號）。
   - 包含打席內發生的暴投 / 捕逸 / 投手犯規（WP / PB / BK）事件。
   - 打席結果套用統一配色徽章（紅、灰、綠、黃、藍綠、藍、紫）。
   - 顯示得分與打點統計。
2. **分局篩選功能**：
   - 可點選查看全部局數或第 1 局至第 9 局（及延長局數），避免紀錄過長疊在一起不易瀏覽。
3. **導出功能**：
   - 支援匯出 **JSON** 格式資料（含完整結構與歷史紀錄）。
   - 支援匯出 **Excel (.xlsx)** 檔案（包含「攻守紀錄表 (Box Score)」與「逐打席紀錄 (Play-by-Play)」雙工作表）。
